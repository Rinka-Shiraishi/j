# PdfCraft — independent upstream archive

**Upstream:** [storytold/pdfcraft](https://github.com/storytold/pdfcraft) (ArtCraft, Acrobat-style project)

This public repository is a separately owned, independently updated **archive**, not a GitHub fork and not affiliated with the upstream maintainers.

- **Mirrored code:** switch to [`upstream/main`](../../tree/upstream/main) or another `upstream/*` branch to browse the original Git files and commit history.
- **Immutable preservation:** each observed upstream branch tip is tagged as `retained/<full-commit-sha>` **before** moving any mirrored branch. Previously seen tips survive upstream branch deletion or force-push.
- **Upstream tags:** copied to `source-tags/*` (never force-overwritten).
- **Synchronization:** approximately once per day (12:17 JST), plus manual GitHub Actions runs.
- **If upstream disappears:** syncing stops safely; no branch or tag is automatically deleted.
- **This default branch:** `main` exists only to host the automatic archive workflow.

**Limits:** Git repository objects only; this does not save Git LFS media, released binaries, GitHub issues/PRs/discussions or non-Git data. GitHub may independently remove hosted content; maintain an off-site copy for stronger preservation. Please consult the original license before using or redistributing the code.
